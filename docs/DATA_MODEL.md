# Data model and dictionary

Generated by `scripts/gen_data_dictionary.py` from `ris/domain/models.py`, `ris/domain/registry.py` and `migrations/`. Do not edit by hand.

## Storage

Each workspace is one SQLite database (`ris.db`, rollback journal, `synchronous=FULL`). Every profile item is a row in `records`: a stable id, kind, optional parent, sort order, verification, confidentiality, origin, revision, checksum, soft-delete tombstone and a JSON payload validated by the model for its kind. Other tables: `records_fts` (full-text search), `variant_versions` (immutable resume versions), `exports` (export log with SHA-256), `settings`, `audit_log` (field names only, never values), `sync_base` and `sync_conflicts`.

Envelope fields shared by every record:

| Field | Meaning |
|---|---|
| verification | Awaiting confirmation; Confirmed; Confirmed with evidence |
| confidentiality | Public; Approved for professional use; Requires review; Confidential |
| origin | Entered manually, Imported, Preliminary (pre-populated), Fictional sample, Generated, Synchronised |
| revision / checksum | Optimistic concurrency and sync change detection |

Fields marked **private** never appear in documents unless explicitly selected (bio-data particulars).
