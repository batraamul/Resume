Resume Intelligence Studio
==========================

1. Drag "Resume Intelligence Studio" onto the Applications folder.
2. The first time, open it from Applications with right-click (or Control-click) → Open → Open.
   On recent macOS versions you may instead need System Settings → Privacy & Security → "Open Anyway".
   This is needed because the community build is not notarised by Apple.
3. Later versions install themselves from inside the app (Settings → Updates) after verifying the
   project's signature.

Your profile is stored in ~/Library/Application Support/Resume Intelligence Studio and is not
affected by installing, updating or removing the application.
